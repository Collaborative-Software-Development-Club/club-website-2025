# 2025 Club Website Redesign

This is the official repository for the 2025 redesign of the Collaborative Software Development Club website.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

-   install the pnpm package manager

### Installation

1. Clone the repo

    \`\`\`sh


    git clone https://github.com/Collaborative-Software-Development-Club/club-website-2025.git


    \`\`\`

2. Install NPM packages

    \`\`\`sh


    pnpm install


    \`\`\`

3. Start the development server

    \`\`\`sh


    pnpm run dev


    \`\`\`
